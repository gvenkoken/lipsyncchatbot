# İş ortağı sistem entegrasyonu destek rehberi

## Amaç ve kapsam

İş ortaklarının uygulama entegrasyonlarında teknik dokümana erişim ve hata bildirim sürecini açıklar. Gerçek API anahtarı veya uç nokta içermez.

## Kullanıcının sorabileceği örnek sorular

- API entegrasyon dokümanına nasıl erişirim?
- Entegrasyonum hata veriyor
- Webhook sorununu nasıl bildiririm?

## İzlenecek örnek adımlar

1. Partner Portalı > Teknik Dokümanlar bölümünü açın.
2. Yetkili teknik kullanıcı rolünüzün bulunduğunu doğrulayın.
3. Hata kodunu, istek zamanını ve kişisel veri içermeyen izleme kimliğini kaydedin.
4. PartnerDesk > Entegrasyon Desteği kategorisine teknik kayıt açın.
